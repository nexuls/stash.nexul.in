# Features

Behaviour built on top of OpenTUI, such as input handling, layout and
rendering, with what each one assumes about the terminal.

## What belongs here

Anything that is behaviour rather than a component. Key and mouse handling,
focus and selection, scrolling, resize response, measurement, frame scheduling.
A note says which layer owns the behaviour, `@opentui/core` or the renderer,
and what it assumes about the terminal, including size changes, reported
capabilities, the alternate screen, and how much work fits in one frame.
