# Features

Behaviour built on top of OpenTUI: input handling, layout, rendering and the
terminal realities each one has to survive.

## What belongs here

Anything that is behaviour rather than a component — key and mouse handling,
focus and selection, scrolling, resize response, measurement, frame scheduling.
A note says which layer owns the behaviour (`@opentui/core` or the renderer),
and what it assumes about the terminal: size changes, reported capabilities,
alternate screen, and how much work fits in one frame.
