# Patches

Workarounds for OpenTUI's rough edges, with what each one costs and when it can
be dropped.

## What belongs here

A patch note starts from the symptom, not the fix: what was observed, which
versions showed it, and what the terminal was doing at the time. Then the
narrowest change that makes it go away.

Every note here carries an exit condition — the upstream fix, release or
refactor that makes the workaround dead code. Without that line a patch
outlives its reason and nobody dares remove it.
