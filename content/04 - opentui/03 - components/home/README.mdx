# Components

Reusable terminal components, and the composition and keyboard model each one
assumes.

## What belongs here

One component per note, with its props, the keys it claims, the focus it
expects to be given, and how it behaves when the available cells shrink below
what it wants. A component that only works inside a particular parent says so
in the first paragraph.
