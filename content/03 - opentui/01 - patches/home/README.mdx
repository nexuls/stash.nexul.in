# Patches

Workarounds for OpenTUI's rough edges, with what each one costs and when it can
be dropped.

## What belongs here

A patch note starts from the symptom. Record what was observed, which versions
showed it, and what the terminal was doing at the time, then the narrowest
change that makes it go away.

Every note also states its exit condition, the upstream fix or release that
makes the workaround dead code. Without that line a patch stays in the codebase
long after the bug it works around is gone.
