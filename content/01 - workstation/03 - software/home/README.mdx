# Software

One note per job, answering "what should I use for this?"

## The shape of a note

1. **My pick**: the tool I use now and why, in a few sentences. Put this first.
2. **Comparison**: a table with OS support, price or licence, and what each tool
   is best and worst at.
3. **The alternatives**: a short section on each tool that made the shortlist,
   and why it lost.
4. **When I would switch**: what would change the decision.

Tag each note with the OSes it covers. A tool that I only mention doesn't need a
note of its own.
