# Tips

Small tricks worth remembering. Each note holds one tip, so search can find it
and a link can point straight to it.

## What belongs here

A tip should be short: the problem, the trick and an example. When a tip grows
past a few paragraphs, it has become a setup note and belongs in **configuration** or **software**.
