# Workstation

How I set up and run a development machine, and why I chose what I chose.

## How this is organised

The folders are sorted by the job you're doing. Operating systems only get
their own folders under **systems**. Anywhere else, if a step differs between
Windows, macOS and Linux, the note shows each OS in tabs, and its tags say which
OSes it covers.

- **systems**: getting an OS ready for development, one section per OS.
- **ecosystems**: installing and managing a language's toolchain.
- **software**: which tool I use for each job, compared with the alternatives.
- **configuration**: setup that moves with me between machines.
- **tips**: small tricks, one per note.

How to *use* a language belongs in that language's own domain. This one only
covers getting the machine ready for it.
