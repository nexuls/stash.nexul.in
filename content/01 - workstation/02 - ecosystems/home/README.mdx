# Ecosystems

Installing a language's toolchain and managing its versions, with one note per
ecosystem.

## The shape of a note

1. **What I use**: the version manager and package manager, with a sentence on
   why.
2. **Install**: shown in tabs per OS wherever the steps differ.
3. **Verify**: one command that proves the toolchain works.
4. **Per-project versions**: how a repository pins its version.
5. **Gotchas**: problems I actually ran into.
