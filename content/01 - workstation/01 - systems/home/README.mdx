# Systems

Getting from a fresh install to a machine that is ready for development, one
section per operating system.

## What belongs here

Only steps that are specific to one OS: installing it, removing what it ships
with, its package manager, its tuning and its upkeep. Anything that works the
same way on every OS goes in **configuration** or **ecosystems**.

## Hardware baseline

What hardware is enough for development work: CPU, memory, storage and
whether a GPU is needed.
