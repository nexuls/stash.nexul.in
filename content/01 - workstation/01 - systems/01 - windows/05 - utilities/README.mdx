# Windows utilities

None of these is required. Each one does a single job better than the built-in
alternative.

| Tool | What it's for |
| --- | --- |
| [PowerToys](https://github.com/microsoft/PowerToys) | Microsoft's power-user toolkit: FancyZones window layouts, PowerRename, a run launcher, a color picker and more. Install this one first. |
| [Windhawk](https://windhawk.net/) | Small mods for the shell and taskbar that Settings doesn't offer. |
| [CrystalDiskInfo](https://crystalmark.info/en/software/crystaldiskinfo/) | SMART health and temperature for SSDs and hard drives. |
| [CPU-Z](https://www.cpuid.com/softwares/cpu-z.html) | Exact CPU, RAM and motherboard details, such as memory speed and channels. |
| [Process Explorer](https://learn.microsoft.com/sysinternals/downloads/process-explorer) | Task Manager with the process tree, open handles and loaded DLLs. |
| [Autoruns](https://learn.microsoft.com/sysinternals/downloads/autoruns) | Everything that starts automatically, including services and scheduled tasks. |

To install them all in one step, use
[winget or WinUtil](/stash/workstation/systems/windows/package-managers).
