# Windows

Turning a Windows install into a development machine.

## Notes

In the order to work through them on a fresh install:

1. **debloat**: remove preinstalled apps and telemetry with WinUtil.
2. **performance-tweaks**: startup apps, visual effects, power mode.
3. **wsl**: a real Linux environment alongside Windows.
4. **package-managers**: winget and Chocolatey, and installing a whole toolset
   at once.
5. **utilities**: the small tools worth having.
