# usePrevious Hook

Stores the previous render's value in a ref so a component can compare across renders without triggering one.

## Implementation

```typescript
import { useEffect, useRef } from "react";

export function usePrevious<T>(value: T): T | undefined {
  const ref = useRef<T | undefined>(undefined);

  useEffect(() => {
    ref.current = value;
  }, [value]);

  return ref.current;
}
```

## Usage Example

Useful for animating only when a value actually changed direction:

```tsx
const previousStep = usePrevious(step);
const direction = previousStep !== undefined && step > previousStep ? "forward" : "back";
```

## When Not To Use It

If the comparison drives rendering rather than an effect, derive the value during render and store it with `useState` instead. Reading a ref that an effect writes always lags by one commit, which is wrong for render-time decisions.
