# useDebounce hook

Debouncing delays a call or a state update until a set time has passed since the value last changed. Search inputs, window resize handlers and auto-save routines all need it.

## Overview

A search input that calls the API on every keystroke sends one request per character. `useDebounce` updates the value once the typing burst stops, so only the last value reaches the network.

## Implementation

The implementation sits beside this guide in [`use-debounce.ts`](./use-debounce.ts):

```typescript
import { useEffect, useState } from "react";

export function useDebounce<T>(value: T, delayMs: number): T {
  const [debouncedValue, setDebouncedValue] = useState<T>(value);

  useEffect(() => {
    const timer = setTimeout(() => {
      setDebouncedValue(value);
    }, delayMs);

    return () => {
      clearTimeout(timer);
    };
  }, [value, delayMs]);

  return debouncedValue;
}
```

## Usage example

In a filter or search component:

```tsx
import { useState } from "react";
import { useDebounce } from "./use-debounce";

export function SearchFilter() {
  const [query, setQuery] = useState("");
  const debouncedQuery = useDebounce(query, 300);

  return (
    <input
      type="search"
      value={query}
      onChange={(e) => setQuery(e.target.value)}
      placeholder="Type to filter results..."
    />
  );
}
```
