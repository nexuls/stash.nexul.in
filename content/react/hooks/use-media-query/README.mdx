# useMediaQuery hook

Reads a CSS media query as reactive state through `window.matchMedia`, instead of a `resize` listener that fires on every pixel.

## Overview

A media query list exposes a `matches` boolean and a change event. The event fires only when the answer changes, while a resize listener measures the viewport on every frame of a drag.

## Implementation

```typescript
import { useEffect, useState } from "react";

export function useMediaQuery(query: string): boolean {
  const [matches, setMatches] = useState(false);

  useEffect(() => {
    const list = window.matchMedia(query);
    setMatches(list.matches);

    function onChange(event: MediaQueryListEvent) {
      setMatches(event.matches);
    }

    list.addEventListener("change", onChange);
    return () => list.removeEventListener("change", onChange);
  }, [query]);

  return matches;
}
```

## Usage example

```tsx
export function Navigation() {
  const isCompact = useMediaQuery("(max-width: 48rem)");

  return isCompact ? <DrawerNav /> : <SidebarNav />;
}
```

## Server rendering

The hook starts as `false` on the server and corrects itself after hydration. When the first paint matters, write the rule in CSS and keep the hook for behavioral differences, such as swapping a drawer for a sidebar.
