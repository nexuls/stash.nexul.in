# useIntersectionObserver Hook

Reports whether a ref'd element intersects the viewport, using a single `IntersectionObserver` instead of scroll math.

## Overview

Scroll handlers force layout reads on every frame. `IntersectionObserver` moves the work off the main thread and delivers batched callbacks only when visibility actually changes.

## Implementation

```typescript
import { type RefObject, useEffect, useState } from "react";

export function useIntersectionObserver(
  target: RefObject<Element | null>,
  options?: IntersectionObserverInit,
): boolean {
  const [isIntersecting, setIsIntersecting] = useState(false);

  useEffect(() => {
    const element = target.current;
    if (!element) {
      return;
    }

    const observer = new IntersectionObserver(([entry]) => {
      setIsIntersecting(entry.isIntersecting);
    }, options);

    observer.observe(element);
    return () => observer.disconnect();
  }, [target, options]);

  return isIntersecting;
}
```

## Infinite Scroll

Place a sentinel element after the last row and fetch the next page when it becomes visible:

```tsx
const sentinel = useRef<HTMLDivElement>(null);
const reachedEnd = useIntersectionObserver(sentinel, { rootMargin: "400px" });

useEffect(() => {
  if (reachedEnd) {
    void loadNextPage();
  }
}, [reachedEnd]);
```

A generous `rootMargin` prefetches before the user hits the bottom, which hides the request latency.
