# useIntersectionObserver hook

Reports whether a ref'd element intersects the viewport, using one `IntersectionObserver` instead of scroll math.

## Overview

A scroll handler forces a layout read on every frame. `IntersectionObserver` does that work off the main thread and calls back in batches, only when visibility changes.

## Implementation

```typescript
import { type RefObject, useEffect, useState } from "react";

export function useIntersectionObserver(
  target: RefObject<Element | null>,
  options?: IntersectionObserverInit,
): boolean {
  const [isIntersecting, setIsIntersecting] = useState(false);

  useEffect(() => {
    const element = target.current;
    if (!element) {
      return;
    }

    const observer = new IntersectionObserver(([entry]) => {
      setIsIntersecting(entry.isIntersecting);
    }, options);

    observer.observe(element);
    return () => observer.disconnect();
  }, [target, options]);

  return isIntersecting;
}
```

## Infinite scroll

Put a sentinel element after the last row and fetch the next page when it becomes visible:

```tsx
const sentinel = useRef<HTMLDivElement>(null);
const reachedEnd = useIntersectionObserver(sentinel, { rootMargin: "400px" });

useEffect(() => {
  if (reachedEnd) {
    void loadNextPage();
  }
}, [reachedEnd]);
```

A `rootMargin` of 400px starts the request 400px before the reader reaches the bottom, which hides the request latency.
