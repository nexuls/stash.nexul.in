# Accessible command menu

A command menu opens on `Cmd+K` or `Ctrl+K` and gives the keyboard direct access to commands, documentation entries and settings.

## Overview

The implementation keeps focus management predictable, follows the dialog and listbox roles, and ships little client code.

![Command menu preview](./command-menu-preview.svg)

## Keyboard navigation

The keys follow the WAI-ARIA patterns for a modal dialog and a listbox:

- `ArrowDown` moves the active item down, and wraps at the bottom.
- `ArrowUp` moves the active item up, and wraps to the end.
- `Enter` runs the active command and closes the dialog.
- `Escape` closes the menu and returns focus to the trigger.

## Component code

The whole component is in [`command-menu.tsx`](./command-menu.tsx):

```tsx
import { CommandMenu } from "./command-menu";

export function AppHeader() {
  const [isOpen, setIsOpen] = useState(false);

  return (
    <>
      <button onClick={() => setIsOpen(true)}>Open Palette (⌘K)</button>
      <CommandMenu
        isOpen={isOpen}
        onClose={() => setIsOpen(false)}
        items={[
          { id: "1", label: "Documentation", onSelect: () => console.log("docs") },
          { id: "2", label: "Settings", onSelect: () => console.log("settings") },
        ]}
      />
    </>
  );
}
```
