# Resizable split pane

Two panes divided by a draggable separator. The separator works from the keyboard and remembers its position between sessions.

## Separator semantics

The separator takes the `separator` role and the attributes the window-splitter pattern requires:

```tsx
<div
  role="separator"
  aria-orientation="vertical"
  aria-valuenow={percent}
  aria-valuemin={20}
  aria-valuemax={80}
  aria-label="Resize panels"
  tabIndex={0}
  onKeyDown={onSeparatorKeyDown}
/>
```

## Keyboard controls

- `ArrowLeft` and `ArrowRight` move the separator by one step.
- `Shift` with an arrow moves it by a coarse step.
- `Home` and `End` jump to the configured minimum or maximum.
- `Enter` collapses the leading pane, or restores it if it is already collapsed.

## Pointer dragging

Use pointer capture rather than document-level listeners, so the drag continues when the cursor leaves the element:

```typescript
function onPointerDown(event: React.PointerEvent<HTMLDivElement>) {
  event.currentTarget.setPointerCapture(event.pointerId);
}
```

During the drag, write the size to a CSS custom property rather than React state. React state re-renders both panes on every pointer move, which drops frames.
