# Virtual list

Renders a window of rows around the scroll position and reserves the rest of the height with a spacer. The number of DOM nodes stays the same whatever the dataset size.

## Overview

Ten thousand rows cost tens of thousands of DOM nodes, which stalls layout and holds memory. Windowing renders the two dozen rows on screen.

## Implementation

```tsx
"use client";

import { useState } from "react";

export function VirtualList<T>({
  items,
  rowHeight,
  height,
  renderRow,
}: {
  items: T[];
  rowHeight: number;
  height: number;
  renderRow: (item: T, index: number) => React.ReactNode;
}) {
  const [scrollTop, setScrollTop] = useState(0);

  const overscan = 4;
  const first = Math.max(0, Math.floor(scrollTop / rowHeight) - overscan);
  const visibleCount = Math.ceil(height / rowHeight) + overscan * 2;
  const last = Math.min(items.length, first + visibleCount);

  return (
    <div
      style={{ height, overflowY: "auto", position: "relative" }}
      onScroll={(event) => setScrollTop(event.currentTarget.scrollTop)}
    >
      <div style={{ height: items.length * rowHeight }}>
        {items.slice(first, last).map((item, offset) => (
          <div
            key={first + offset}
            style={{
              position: "absolute",
              top: (first + offset) * rowHeight,
              height: rowHeight,
              width: "100%",
            }}
          >
            {renderRow(item, first + offset)}
          </div>
        ))}
      </div>
    </div>
  );
}
```

## Variable row heights

Fixed heights keep the arithmetic to one multiplication. Variable heights need row measurement and a cumulative offset index, which is far more code. Reach for a library before writing that by hand.

## Accessibility

Windowing hides the count of rows from assistive technology. Set `aria-setsize` to the full length and `aria-posinset` to the absolute index on each row.
