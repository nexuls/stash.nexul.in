# usePrevious hook

Stores the previous render's value in a ref, so a component can compare across renders without causing one.

## Implementation

```typescript
import { useEffect, useRef } from "react";

export function usePrevious<T>(value: T): T | undefined {
  const ref = useRef<T | undefined>(undefined);

  useEffect(() => {
    ref.current = value;
  }, [value]);

  return ref.current;
}
```

## Usage example

Animate only when a value changed direction:

```tsx
const previousStep = usePrevious(step);
const direction = previousStep !== undefined && step > previousStep ? "forward" : "back";
```

## When not to use it

If the comparison drives rendering rather than an effect, derive the value during the render and hold it in `useState`. A ref that an effect writes always lags one commit behind, which is the wrong answer for a render-time decision.
