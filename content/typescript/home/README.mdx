# TypeScript

Notes on using the type system to remove whole classes of bug rather than to
decorate code that already works.

## How this is organised

- **patterns** — modelling techniques, with the cost of each one stated plainly.

A pattern earns a note here when it changed how a real module was written, not
because it is clever. Where a technique has a worse day than its reputation
suggests, that is in the note too.
