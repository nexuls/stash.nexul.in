# Stash

Stash is Arif Sardar’s personal engineering knowledge base: a searchable archive of reusable components, utilities, notes, patterns, experiments, and references.

The application is currently at its foundation stage. The product plan and current implementation status live in the repository:

- [Agent and contributor guide](AGENTS.md)
- [Current project state](docs/PROJECT_STATE.md)
- [Prioritized backlog](docs/TODO.md)
- [Architecture documentation](docs/architecture/)

## Local development

```bash
bun install
bun run dev
```

The current validation commands are `bun run lint` and `bun run build`. A unified check command, tests, and content validation are planned and tracked in the backlog.
